# LaTeX Training

Course materials for the LaTeX training program.

## Contents

- **Course Outline.pdf** — overview of the course structure and schedule
- **Day-wise Course Materials/** — daily lecture/reference PDFs (Day 1–7)
- **Hands-on Practice Code Sheets/** — in-class practice exercises (PDF + LaTeX source) for each day
- **LaTeX Source Files/** — the `.tex` source files used to produce the Course Outline and Day-wise Course Materials PDFs

## Course Days

1. Setup and Document Anatomy
2. Math Mode for Economists
3. Tables, Figures, and Regression Output
4. Citations and Bibliography
5. Document Structure and Long Documents
6. Journal Templates and Formatting
7. Troubleshooting and Independent Mastery
